# Prague Final Portfolio

This folder contains the full working materials for the photography final portfolio:
three optional creative project tracks, each developed into a complete, shoot-ready
concept with a numbered 10-image sequence, shooting notes, a location/lighting
schedule, and a one-page Artist Statement draft.

## Guiding principle (applies to all tracks)

The brief explicitly rewards **subjective, metaphorical storytelling over literal
documentation**. So for every track, lock three things *before* shooting:

- **An emotional thesis** — one sentence stating what *feeling* the place/motif is,
  not what it *is*.
- **A visual grammar** that enforces that thesis: a deliberate palette (color vs.
  black-and-white), a recurring compositional device (e.g., always shooting through
  something, always off-center, always tight crops), and a consistent light /
  time-of-day.
- **Sequence as narrative** — order the 10 images like a piece of music: an
  establishing mood → tension / development → a turn → resolution. The numbering is
  graded, so treat it as authored, not arbitrary.

## Recommended next steps

1. **Pick a track.** Recommendation: Track 2 "Iron Lace" — most tightly focused and
   visually distinctive, lowest cliché risk.
2. Lock your **thesis sentence** and **visual grammar** before shooting.
3. Scout + shoot in **two sessions** (different light) to guarantee variety.
4. Edit down ruthlessly to 10, then **sequence**, then write the statement *after*
   you see the final order.
5. Export to spec, zip, and email (and pre-email the instructor first if you go
   Track 3 — see that file).
