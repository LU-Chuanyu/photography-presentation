# 图片来源对照表 / Image Sources

为什么 Sudek 的照片"难找、难拿到文件"：Sudek 1976 年去世，作品在多数国家**受版权保护到约 2046 年**。
因此各大博物馆通常**只提供低分辨率预览图，不提供高清 CC0 下载**。课堂展示用预览图通常没问题，
但请在末页统一标注来源；**不要当作公有领域素材自由再利用**。

> 把图片放进 `images/` 文件夹（命名见 `images/README.md`）后，运行 `python build_pptx.py` 自动嵌入。

| Internet Archive | 画册 / 图录扫描，可整本下载 | https://archive.org/details/josef1 |

## 使用建议

1. 课堂展示：用页面预览图即可；每张记下"作者 / 标题 / 收藏机构 / 链接"，填进末页来源页。
2. 想要更高清：优先翻 **Sudek Project** 与 **NGC**，它们的图通常最大。
3. 真正无版权顾虑的：仅极少数进入公有领域者，或 **Wikimedia Commons** 上标注自由授权者，才可自由再利用。
